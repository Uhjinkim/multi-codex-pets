# Multi Codex Pets

[![English](https://img.shields.io/badge/English-475569?style=for-the-badge)](README.md)
[![한국어](https://img.shields.io/badge/한국어-2563eb?style=for-the-badge)](README.ko.md)

코딩 에이전트의 활동에 반응하는 데스크톱 펫입니다.
여러 펫을 화면에 띄우고, 세션을 연결하고, 펫마다 소리와 모습을 꾸밀 수 있습니다.

## 설치

**Apple Silicon Mac · macOS 13 이상**

[**Mac용 다운로드**](https://github.com/Uhjinkim/multi-codex-pets/releases/latest/download/MultiCodexPets.dmg)

DMG를 열고 **MultiCodexPets.app**을 **Applications(응용 프로그램)** 폴더로
드래그한 뒤 실행하세요. 메뉴 막대 아이콘에서 **설정**을 열어 펫을 선택하면 됩니다.

터미널에서 최신 버전을 다운로드하고 설치 창을 열 수도 있습니다.

```bash
curl -fL --retry 3 -o "$HOME/Downloads/MultiCodexPets.dmg" \
  "https://github.com/Uhjinkim/multi-codex-pets/releases/latest/download/MultiCodexPets.dmg" \
  && open "$HOME/Downloads/MultiCodexPets.dmg"
```

설치 창에서 앱을 **Applications** 폴더로 드래그하면 설치가 끝납니다.
업데이트할 때는 실행 중인 앱을 종료하고 새 버전으로 교체하세요.
기존 펫, 소리, 설정은 유지됩니다.

## 내 취향대로 사용하기

- **펫 선택:** 여러 펫을 동시에 띄우고, 설치된 Codex의 기본 펫이나 직접 추가한
  커스텀 펫을 사용할 수 있습니다. 앱에 펫 모음이 포함되어 있지는 않습니다.
- **에이전트 연결:** Codex, Claude, Orca, Antigravity 세션을 연결하면
  에이전트의 활동이 펫의 애니메이션으로 표시됩니다.
- **움직임 선택:** 세션 따라가기, 돌아다니기, 원하는 동작 재생 중에서 고르세요.
  드래그로 위치를 옮기거나 위치를 잠글 수도 있습니다.
- **소리 설정:** 클릭음과 알림음을 직접 추가하세요.
  전체 펫과 개별 펫의 볼륨·음소거를 각각 조절할 수 있습니다.
- **펫 꾸미기:** 이름을 바꾸고 이름표를 꾸미거나 다른 모니터로 옮길 수 있습니다.

펫을 우클릭하면 설정과 빠른 동작을 사용할 수 있습니다.
설정의 펫 격자에도 각 펫의 **동작 미리보기**, **소리 설정**, 옵션 메뉴가 있습니다.

## V2 펫의 커서 바라보기

V2 펫을 우클릭하고 **커서 바라보기**를 선택하세요.

- **끄기:** 기본 애니메이션을 유지합니다.
- **항상:** 쉬거나 입력을 기다릴 때, 작업이 완료되었을 때 커서를 바라봅니다.
- **흔들 때만:** 마우스를 흔들면 잠깐 커서를 바라봅니다.

설정은 선택한 펫에만 적용됩니다. 작업 중 애니메이션, 드래그, macOS의
동작 줄이기 설정이 우선합니다. ‘흔들 때만’은 마우스 움직임을 감지하므로
시스템의 커서 확대 기능을 켤 필요는 없습니다.

## 펫과 소리 추가

설정의 펫 검색에서 Codex Pets의 캐릭터를 찾아보세요.
사이트 안내에 따라 설치한 뒤 **펫 새로고침**을 누르면 됩니다.
커스텀 펫의 기본 저장 위치는 `~/.codex/pets`입니다.

각 펫의 소리 설정에서는 이름이나 별칭으로 Myinstants를 검색할 수 있습니다.
사이트에서 미리 듣고 다운로드한 파일을 클릭음 또는 알림음으로 추가하세요.
추가한 소리도 미리 들어 보고 사용할 소리를 고를 수 있습니다.

## 세션 알림

**설정 → 동작**에서 어떤 활동 변화에 소리를 낼지 선택하세요.
Orca 에이전트가 다른 에이전트에 메시지를 보낼 때의 알림도 별도로 켤 수 있습니다.
메뉴 막대의 **세션 소리 알림**으로 세션 알림을 켜거나 끌 수 있습니다.

## 개인정보

세션 추적은 로컬 데이터를 사용합니다. 대화 데이터를 전송하거나 사용 통계를
수집하지 않습니다. 펫·소리 검색은 브라우저에서 해당 사이트를 엽니다.
